## Selected projects

[Read the verified agent reliability case study](https://github.com/Lkhanaajav/mcp-trajectory-evals/blob/main/docs/case-study.md).

### [mcp-trajectory-evals](https://github.com/Lkhanaajav/mcp-trajectory-evals)

Python evaluation harness for tool-using agents. Runs against a real MCP server and scores tool selection, arguments, numeric/date grounding, efficiency, and required answer content. Includes reference-plan, replay, and live-model runners plus CI regression gates. Deterministic reference runs validate the harness and server contract; they do not measure live-model accuracy.

### [timeseries-mcp](https://github.com/Lkhanaajav/timeseries-mcp)

Typed statistical tools for time-series analysis with schema-validated outputs, bounded responses, and path-restricted CSV ingestion. The tool interface does not execute model-generated code. Built with Python, FastMCP, Pydantic, NumPy, SciPy, and statsmodels.

### [TraceLab](https://github.com/Lkhanaajav/tracelab-ai-agent-observability)

Python/FastAPI and React/TypeScript project for tracing agent runs, inspecting tool calls and evaluation results, and comparing failures with a baseline.

### [Perception research](https://github.com/Lkhanaajav/live_test_scooter_project)

University of Oklahoma work on monocular perception, segmentation, BEV transformation, and navigable-path extraction. See the repository for implementation details. The project explores segmentation, geometry, and path-planning behavior on embedded hardware.
