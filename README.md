## Selected projects

### [mcp-trajectory-evals](https://github.com/Lkhanaajav/mcp-trajectory-evals)

Evaluation harness for tool-using agents. Runs against a real MCP server and scores tool selection, arguments, numeric/date grounding, efficiency, and required answer content, with CI gates that fail on regressions. [Case study](https://github.com/Lkhanaajav/mcp-trajectory-evals/blob/main/docs/case-study.md).

### [timeseries-mcp](https://github.com/Lkhanaajav/timeseries-mcp)

Typed statistical tools for AI agents: schema-validated outputs, bounded responses, and path-restricted CSV ingestion. Tools never execute model-generated code. Python, FastMCP, Pydantic, NumPy, SciPy, statsmodels.

Python/FastAPI and React/TypeScript dashboard for tracing agent runs, inspecting tool calls and eval results, and comparing failures against a baseline.
